# 三層樓美術接線（以 layout.js 為準）

基準分支：`redesign-elem-jh`，規格修正提交 `141df31`。成果分支：`codex/three-floor-layout`。此分支納入基準分支的劇情與引擎，供差異比對；不合併回 `main` 或 `redesign-elem-jh`。

## 目前入口與唯一格局來源

正式遊戲入口為 `index.html`，由 `python3 build.py` 重建。原本獨立的 `redesign.html`、`redesign-layout.js`、`redesign-preview.js`、`redesign.css` 已撤下，避免保留兩套格局。房間、門、座位、SPOTS、樓梯與電梯連結全部沿用 `src/layout.js`。

樓層仍使用 Claude 引擎的平面偏移：每層 36 × 18，X 偏移為 0、48、96；樓層索引是 0、1、2。`floorOf(x)` 判斷樓層，只顯示玩家所在樓層。不改成另一套 y 堆疊的座標，也不修改 NPC、人流、兩天劇情或小遊戲。

## 接入內容

- 門牌沿用 `world.js` 按 `ROOMS`、`door` 產生的牌子；補充相同門洞內的門柱與門檻，及 `CORE` 附近的樓梯牌／電梯樓層指示。
- 國小安親與國小美語桌面本體高度 0.53；國中桌面本體 0.72。國小椅面頂端 0.35、國中椅面頂端約 0.468。人物坐姿一併對齊，避免矮椅上的小朋友浮空。
- 課桌改用依現有一公尺寬碰撞區生成的桌板、金屬腳架與書籃；國小與國中共用造型、使用不同高度，尺寸不再套用舊版 1.2 公尺桌。
- `art.js` 裝飾依 `ROOMS`、`CLASS_SEATS`、`CORE` 生成：踢腳板、門檻、門柱、教室課本／講義／白板托盤、櫃台電話／鍵盤、影印機與辦公桌文件。
- 刪除 `art.js`、`art_models.js`、`art_models_fix.js` 已停用的舊平面房間裝飾與高中門牌覆寫，保留通用材質／模型工具。
- 移動成本提示與實際扣費都讀 `src/floor-travel.js` 的 `floorTravelQuote()`。手動選樓層的按鈕會先顯示分鐘與體力，自動尋路使用相同的 `floorCost` 回呼。

沒有新增家具碰撞，也沒有變更房間、門洞、既有桌椅碰撞範圍或任何劇情地點。

## 與獨立原型的差異（供 Claude 比對）

以下都是撤下原型、採用既有資料的對照，**不是要求修改 layout.js**。

| 項目 | 原獨立原型 | 本次沿用的基準 |
|---|---|---|
| 每層尺度 | 30 × 22 | 36 × 18 |
| 樓層表示 | 局部 x/z，加 y 樓高 | X 偏移 0／48／96；f=0／1／2 |
| 美語教室 | 二樓 | 一樓 `english`；沿用基準，不自行搬動 |
| 二年級主教室 | `care2`／`careBoard` | `g2`／`g2door`／`g2podium` |
| 九年級主教室 | `grade9`／`podium` | `c9`／`c9door`／`c9podium` |
| 家長等候 | `parentWait` | 既有 `sofa`／`lobby` |
| 接送核對 | 額外 `pickup` 點 | 使用現有劇情目標，不新增地點 |
| 手機籃 | `phoneBasket` | `lockers` |
| 電梯 kind | `elevator` | `elev` |
| 安親座位 | 每教室 8 張 | `CLASS_SEATS` 每教室 9 張；不改座位數 |
| 班導線 id | 原型 `homeroom` | 基準 `jh`；不改劇本 id |

可直接併入的內容是這份美術與成本提示。需先確認再動的項目是任何房間／門／座位／SPOTS 修改；本次沒有這些修改。原規格說美語在二樓，但基準程式放在一樓，這個差異留給整體設計確認，不改已接好劇情的格局。

## 樓梯與電梯成本

保留基準引擎既有平衡：樓梯每層 0.5 遊戲分鐘；有 hp 的職業每層扣 1 體力，沿用最低保留 1 的規則。沒有 hp 的職業不新增隱藏體力值。

電梯一般候梯與搭乘共 0.6–1.4 分鐘；17:25–18:05 沿用基準高峰額外加 1.5 分鐘。本次補上 21:00–21:30 國中放學也額外加 1.5 分鐘。跨兩層的直達電梯連結只扣一次。提示顯示估計範圍，完成移動後 banner 顯示本次實際花費。

這裡的候梯是扣遊戲分鐘，不是新增現實秒數倒數、電梯容量或 NPC 排隊模擬。既有 `portalHop`、選樓層、A* 跨樓層連結都不換架構。

## 驗證與限制

`npm run test:layout` 不需要瀏覽器，直接載入實際 layout、world、美術 wrapper 與 Three 替身，驗證：

- `ROOMS`、`SPOTS`、`WALLS`、`PORTALS`、`CLASS_SEATS` 與 `141df31` 的資料雜湊完全一致；CI 不需取得歷史提交。
- 從一樓大門可到達 45 個命名地點，沿每 0.05 單位採樣檢查尋路片段。
- 各教室共 71 個座位的入座移動、國小／國中椅子尺度與小朋友坐姿。
- 147 個新裝飾留在所屬房間／門口，沒有跨房間擺放。
- 樓梯、普通候梯、下午／晚間高峰，以及實際 engine 的 `floorCost` 時間／體力扣除。

已重建 `index.html` 並檢查相關 JavaScript 語法與 diff。這些驗證使用 Three 替身，不能證明真實 WebGL 畫面、手機操作或幀率。此環境仍缺少所需的瀏覽器控制技能，未執行完整 Playwright 遊玩矩陣與實機畫面驗證；推送後可由既有 CI 執行完整測試。

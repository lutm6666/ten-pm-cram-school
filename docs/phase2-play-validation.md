## 實際生效的建模程式

`build.py` 先拼接 world → art → art_models → art_models_fix → art_phase2 → art_phase2_env → story/light/ui/perf，之後才 boot 建立世界。
櫃台由 `fmReceptionDesk` 生效；主任桌、休息室桌由 `art_phase2_env.js` 的 furn 攔截生效；B 班桌椅由 `art_phase2.js` 生效；人物沿用該檔包裝後的原方塊骨架。
上述桌板在基準版本已使用 BoxGeometry，因此未重做既有實心桌板修正。
儲存庫原先的 index.html 落後於 src；本次重新建置包含既有 Phase 2 來源，所以生成檔差異較大。

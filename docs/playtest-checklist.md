# 試玩檢查清單（給代玩測試用）

試玩網址：<https://lutm6666.github.io/ten-pm-cram-school/>
（國小＋國中版，已合併到 main。）
可以在瀏覽器清除網站資料重玩。

## 怎麼玩

- 標題畫面選一個位子 → 開始。玩完第一天，標題畫面會出現該位子的「第二天」。
- 畫面上方卡片是下一件事，按「帶我去」會自動走過去；走到後右下角出現動作按鈕。
- 5 個位子 × 2 天 = 10 輪。每輪約 15–25 分鐘；設定裡可以把時間流速調成「緊湊」。

## 已經確認的現實設定（遊戲必須符合）

- 這棟樓只有國小四～六年級安親＋國中部；一～三年級在另一棟。
- 玩家的安親線是四年級（蔡老師）；林老師五年級、吳老師六年級。
- 三、四年級週三、週五半天；五、六年級只有週三半天。
  - 第一天週二：全部整天，15:20 出發接人、15:50 回到安親班。
  - 第二天週三：全部半天，12:20 出發、12:50 回來，13:00–13:30 午休（趴桌、午睡枕）。
- 安親老師 11:30 到班；國中班導 13:30 到班；國中 18:00–21:00 上課；櫃台 17:30–18:00 最忙。
- 安親老師從出發接人（週二 15:20、週三 12:20）到收拾教室都不應該有「空檔・可以四處看看」（週三 13:00–13:30 午休除外）。接人路程直接跳到回教室。
- 安親教室沒有講台；老師辦公桌在白板旁邊（不在白板正前方）。白板寫的是「評量進度」，各班學校作業不同。
- 評量本是學期初向書商買的，不用影印；要印的是考卷、學校考卷的解答、練習卷、補充講義。
- 單純問班由櫃台在大廳接待；嚴肅或重要的事才請到諮詢室。
- 國中：遊戲時間是第一次段考前一週，在做複習（複習卷、錯題檢討），不是教新進度。
  - 九年級：相似形。八年級：乘法公式與多項式（可含平方根）。不應出現畢氏定理。
  - 國中段考用分數，不用 A/B/C。
- 家長群組裡只會有群組成員（家長），不會有陌生號碼。
- 同事閒聊不會特意講固定的接送時間。

## 每個場景都要看

1. **人在不在**：對話提到的人，畫面上有沒有？沒提到、已經離開的人，畫面上是不是還在？
2. **在哪裡**：人和事件發生的地點合不合理（例如寫作業時間，小朋友不會跑到走廊）。
3. **時間**：時鐘、作息、到班／放學時間有沒有違反上面的設定？有沒有「快轉」或「空檔」出現在不該出現的時段？
4. **文字**：用語是不是台灣國小安親／國中補習班會用的？有沒有殘留高中版用語（高三、學測、模考、B 班、自習室、助教）？
5. **畫面**：人物或模型疊在一起、卡在原地、穿進家具、浮在空中、朝錯方向（椅子背對桌子）。
6. **操作**：按鈕按不到、「帶我去」走不到、卡住無法往下。

## 回報格式

每個問題一行，照這個格式：

```
[位子／第幾天] 遊戲時間｜地點｜問題（看到什麼 vs. 應該怎樣）｜嚴重度：卡關／邏輯錯／小瑕疵
```

例：

```
[安親／第一天] 18:20｜四年級教室｜文字說只剩小米，但小宇還坐在位子上｜邏輯錯
```

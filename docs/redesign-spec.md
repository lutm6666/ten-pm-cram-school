# 改版規格：國小＋國中補習班（2026-10-14）

把「高中補習班」整體改成台灣最常見的型態：**國小安親＋國小美語＋國中補習**。
本文件取代 `content-audit.md` 中所有高中專屬的項目（學測、級分、高三 B 班、試聽家長進教室等），其餘仍適用的項目見最後一節。

## 2. 國小作息（遊戲依據）

- 低年級（一、二年級）只有**週二**上整天，其他天中午放學。
- 中、高年級只有**週三**上半天。
- 半天：約 12:00–12:40 放學，大多在學校吃過午餐。
- 整天：約 15:30–15:40 放學（安親老師 15:20 出發，15:50 帶回補習班）。

所以二年級安親老師：
- **第一天（週二）**：整天，15:20 出發接人。
- **第二天（週三）**：半天，12:20 出發接人，接著午休、寫作業的完整流程。

兩天正好呈現兩種節奏。

## 3. 五個可玩角色與一天的流程

時間是遊戲裡排定的時刻。各線一天約 10～14 個主要步驟，空檔可以快轉。

### 3-1 二年級安親老師（蔡老師）｜11:30–18:30（少數孩子留到 19:00）

工作重點：檢查作業與評量、維持秩序、處理糾紛、和家長溝通。

**第一天（週二，整天）**
| 時間 | 事件 |
|---|---|
| 11:30 | 到班，打掃二年級教室，批改昨天的評量 |
| 12:30 | 週二低年級（一、二年級）都是整天，中年級也是整天；午間沒有人接回，安親樓層很安靜，專心批改 |
| 13:40 | 下樓印評量（跟國中部搶影印機） |
| 14:30 | 家長來詢問（張媽媽），櫃台請你下樓 |
| 15:20 | 出發去國小接人（點名：誰還沒出來） |
| 15:50 | 回到班上，開始寫作業、評量、複習 |
| 16:30 | 小宇說他寫完了（檢查作業） |
| 17:00 | 安安的聯絡簿沒簽（家長出差） |
| 17:30–18:00 | **放學高峰**：家長陸續來接，接送名單核對（名單外的人來接） |
| 18:00 以後 | 剩下寫太慢或家裡晚來的孩子（小米），留到 18:30／19:00 |

**第二天（週三，半天）**
| 時間 | 事件 |
|---|---|
| 11:30 | 到班，打掃、批改；確認今天下雨要帶傘 |
| 12:20 | 出發接人（八個人，三把傘） |
| 12:50 | 回到班上，換室內鞋、上廁所、刷牙 |
| 13:00–13:30 | 午休：有人睡不著、有人偷聊天、小米想媽媽 |
| 13:30 | 起床，寫作業、評量、複習 |
| 15:00 | 點心時間 |
| 15:30 | 糾紛：橡皮擦事件 |
| 16:00 | 訂正、複習；安安媽媽出差回來（第二天回來，和第一天的說法一致） |
| 17:00–18:00 | 放學高峰 |
| 18:00 | 收尾：教室打掃、明天的評量放好 |

### 3-2 國中班導（新角色，九年級班）｜13:30–21:30

工作重點：
- 班務行政、影印各科考卷、批改考卷、登記成績、教室整潔。
- 上課前掌握到班狀況，時間內沒到的要打電話給家長。
- 課間簽聯絡本、維持秩序、處理學生的各種需求。

**第一天**
| 時間 | 事件 |
|---|---|
| 13:30 | 到班：班務信箱、今天要印的考卷清單（數學、英文、理化） |
| 14:00 | 影印：和安親班、國小美語搶影印機 |
| 15:00 | 批改昨天的段考複習卷，登記成績（學生自己加的總分有錯） |
| 16:30 | 打掃教室，排今晚的座位（段考前，有人要求換座位） |
| 17:20 | 學生陸續到班吃晚餐（便當統計、有人沒帶錢） |
| 17:50 | **到班確認**：有人沒刷卡、沒到 → 打給家長（阿翔說在路上，其實在網咖） |
| 18:00 | 授課老師上課；你在後面巡、處理手機籃 |
| 19:25 | 下課十分鐘：簽聯絡本、子晴要討論演講比賽、品妤胃痛；八年級的小柏想溜去 7-11 |
| 19:35 | 第二節：班上秩序（有人傳紙條） |
| 21:00 | 放學：家長接人、打給沒接到的家長；整理教室 |

**第二天**
- 段考倒數五天（第一天倒數六天）：段考模擬、家長回覆聯絡本。
- 昨天選擇的後續：阿翔的網咖、子晴的演講、阿哲的退費。

### 3-3 跑堂的國中數學老師（許老師）｜17:30–21:15

工作重點：
- 課前 10–30 分鐘到班，確認班導準備好講義和考卷。
- 課堂要帶動氣氛、適時講笑話和分享故事，用有趣又深入淺出的方式教知識和人生觀念。

**第一天**
| 時間 | 事件 |
|---|---|
| 17:30 | 從另一間補習班趕過來（跑堂）；機車停哪裡 |
| 17:40 | 跟班導確認：講義印好了嗎？考卷少了一份？投影機？ |
| 17:50 | 試聽的國三生已經坐好，家長在外面等 |
| 18:00 | 第一節：第一次段考複習（相似形），檢討複習卷；全班一半找錯對應邊。小遊戲改成「講笑話或講故事」的時機選擇 |
| 18:40 | 阿哲睡著了／手機響了 |
| 19:25 | 下課：家長在走廊攔住你（試聽家長問「跟對面差在哪」） |
| 19:35 | 第二節：林媽媽的電話剛結束，班導告訴你阿哲想退費 |
| 21:00 | 下課：品妤留下來問題目；你還要趕回家備另一間的課 |
| 21:10 | 主任找你談寒假排課 |

**第二天**
- 第一天的選擇有後續：試聽生報名了沒、阿哲還來不來。
- 段考倒數五天：先上八年級，再上剛考完模擬考的九年級。

### 3-4 櫃台老師（小芸）｜13:30–21:30

工作重點：
- 熟悉各老師分享與提出的大小事。
- 收費、接電話、轉達家長問題。
- **17:30–18:00 最忙**：同時接電話、廣播下課、接收家長資訊、收費。

**第一天**
| 時間 | 事件 |
|---|---|
| 13:30 | 到班：昨天的便利貼、未接來電、今天要收費的名單 |
| 14:30 | 新生詢問電話；國小美語的分班測驗 |
| 15:30 | 安親老師去接人，櫃台幫忙看著大廳 |
| 16:30 | 主任交代：缺課補課的家長要回電 |
| 17:30–18:00 | **放學高峰（核心玩法，見第 6 節）** |
| 17:20–17:55 | 國中生到班（和安親放學高峰重疊）：刷卡、便當、忘了帶東西 |
| 18:10 | 回覆家長訊息，整理各老師交辦的事 |
| 19:25 | 國中下課：林媽媽打來要找許老師 |
| 21:00 | 國中放學；21:15 日結：對帳（現金、收據），關門 |

工作重點：

**第一天**

|---|---|
| 13:00 | 到班：總部週報、續班名單、本月支出 |
| 14:00 | 設備：影印機又壞了，冷氣漏水（叫修或自己處理，預算） |
| 15:00 | 招生：國小美語暑後招生、國中段考後衝刺班傳單 |
| 16:00 | 安親老師反映人手不夠 |
| 17:30 | 放學高峰：家長客訴（作業沒檢查到、孩子在班上被欺負） |
| 17:50 | 試聽家長在大廳等，你去接待 |
| 18:40 | 巡堂：國中班從門窗看進去 |

## 4. 格局（交給 GPT 做 3D）

三層樓，電梯一部、樓梯一座。安親與國中部分在不同樓層，彼此不干擾，但都會經過一樓。

| 樓層 | 空間 |
|---|---|
| 1F | 大門、大廳（家長等候沙發）、櫃台、主任室、刷卡機、鞋櫃、接送等候區、教材室（影印機） |
| 2F | 國小安親：一年級、二年級、中年級三間教室；午休區（可共用二年級教室，桌椅收攏）；國小美語教室；安親老師辦公桌 |
| 3F | 國中部：七、八、九年級教室各一（九年級是班導線的主教室）；自習／課輔室；國中老師休息室（跑堂老師放東西的地方） |

設計原則：
- 每層有清楚的「門牌」與招牌，招牌只描述空間，不暴露劇情。
- 安親線主要在 1F、2F；國中班導、授課老師在 1F、3F；主任、櫃台三層都會去。
- 電梯要等、樓梯耗體力；放學高峰電梯塞爆（見 content-audit J4）。
- 安親孩子的桌椅與國中桌椅尺寸不同，不再共用教室，也沒有「桌椅復原」問題。

## 6. 核心玩法：放學高峰（17:30–18:00）

這是改版後最重要的玩法，同時解決 content-audit 的 F3（空檔沒事做）與 F4（時間壓力弱）。

- 櫃台線在這 30 分鐘內會有多件事**同時**發生，玩家一次只能做一件：
  - 電話響
  - 家長到櫃台要繳費
  - 安親老師請你廣播「二年級小宇，家長來接了」
  - 家長留話要轉告老師
  - 國中生來刷卡、問便當
- 每件事都有等待時間，沒處理的會變成後果：
  - 漏接電話會變成之後的客訴
  - 廣播太慢，家長在門口等到生氣
  - 收費算錯，日結對不上
- 安親線與主任線在同一時段也有高峰，但內容不同：
  - 安親線：接送名單核對、孩子哭、家長要談作業。
  - 主任線：當場的客訴、設備故障。
- 技術上需要新的「多工佇列」系統（同時出現多個可互動目標，各有倒數）。**由 Claude 實作**。

## 7. 跨線交會（同一天、不同視角）

尾聲仍保留「五個人，同一間補習班，同一天」。至少以下交會點要在各線中一致：

| 時間 | 交會 |
|---|---|
| 14:00 | 影印機：班導印考卷、安親印評量、主任叫修 |
| 15:20 | 安親老師出發接人，櫃台看大廳 |
| 17:30–18:00 | 放學高峰（五條線中四條都在場） |
| 17:30–18:00 | 安親放學高峰＋國中到班（五條線中四條都在場） |
| 17:50 | 試聽家長到大廳；主任接待、櫃台招呼、授課老師上樓前遇到 |
| 17:50 | 國中到班確認：班導打電話給阿翔家長，櫃台接到阿翔媽媽回電 |
| 19:25 | 國中下課：林媽媽來電（櫃台）、阿哲找班導要退費單、許老師被家長攔住、主任接到小芸說要辭職 |
| 21:00–21:30 | 國中放學與日結 |

每個交會點由一條線的選擇決定另一條線看到的事件版本（content-audit J5）。

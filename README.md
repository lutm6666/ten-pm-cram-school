# 晚上十點下課

補習班打工人的一天。一款 3D 網頁小遊戲，靈感來自晶圓廠打工遊戲 fab24hr，把場景換成台灣的補習班：一棟三層樓、國小四～六年級安親加國中部。

打開 `index.html` 就能玩，不用安裝。手機、電腦都可以。

## 玩法

選一個位子，過同一間補習班的同一天。五個位子看到的事情不一樣，有些人和事會在不同位子之間接起來。

| 位子 | 上班時間 | 在做什麼 |
|---|---|---|
| 四年級安親老師（蔡老師） | 11:30–19:00 | 打掃、改評量；去國小接人；看學校作業、寫評量進度；處理小朋友的糾紛；放學時一個一個交給家長 |
| 九年級班導（鄭老師） | 13:30–21:30 | 印考卷、登成績、打掃教室；確認到班、沒到的打給家長；簽聯絡本、顧秩序、處理學生的大小事 |
| 跑堂數學老師（許老師） | 17:30–21:30 | 下午在別間補習班上課，晚上趕來；確認講義、帶氣氛、段考前帶全班複習 |
| 櫃台（小芸） | 13:30–21:30 | 收費找零、接電話、轉達家長的話、廣播放學；17:30–18:00 的放學高峰最忙 |
| 主任（何主任） | 13:00–21:30 | 招生和續班、家長、老師人手、影印機和冷氣、總部的週報 |

- **第一天是週二**，國中第一次段考前一週。國小四～六年級都上整天，15:20 出發去接人。
- **第二天是週三**：國小全部中午放學，12:20 接人、接回來午休。玩完某個位子的第一天，就能玩那個位子的第二天，前一天的選擇會接下去。
- 三層樓：1F 大廳、櫃台、主任室、國小美語；2F 國小安親；3F 國中部。樓梯比較快但耗體力，電梯要等，放學時更久。
- 時鐘會走，每件事都有期限，遲到會有後果。跟著頭上有紅色「！」的人或地方走，或按「帶我去」。
- 頭上有黃色「？」的人有支線；地上金色星星在閃的地方有東西可以撿；有「i」的地方可以看說明。
- 每一輪會隨機發生兩件事，例如地震、停電、下雨、蟑螂、外送珍奶，安親另有跌倒、學校來電、多送的布丁。
- 走到人物旁邊可以「聊聊」，可以點問題，也可以自己打字問。回答會隨時段、你是誰、第一天或第二天而改變。
- 下班前後還有加班的事：沒人接的學生、晚上的家長群組、主任的「五分鐘就好」。加班時間會記在結算裡。
- 任意三個位子玩過，會解鎖「一個月後」；五個位子都玩過，結尾多一段「回到那個週二」。

右上角「設定」可以調音量、時間流速（悠閒／標準／緊湊）、拖曳靈敏度、鏡頭距離和字體大小。

玩完可以產生「成績卡」圖片分享。GitHub Pages 版可以「加到主畫面」，像 App 一樣全螢幕開啟，玩過一次之後沒網路也能開。

操作：WASD／方向鍵或點地板走路，E 互動。拖曳畫面轉視角（上下拖改俯角），雙指或滾輪縮放，Q/R 旋轉，「⟲」讓視角歸位。手機有方向鍵。走到樓梯或電梯旁可以選樓層。

  cast.js          劇情共用的人物站位

  minis.js         共用小遊戲

  events.js        隨機事件

  chats.js         跟人物閒聊

`links.js`、`extras2.js`、`consistency*.js`、`art_phase2_env.js`、`art_phase2_light.js`、`art_phase2_story.js` 是高中版留下的檔案，目前不會被打包。

3D 使用 [three.js r128](https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js)（CDN 載入）。

## 建置

```bash
python3 build.py                          # 產生 index.html（GitHub Pages 用）
python3 build.py --artifact https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js artifact.html  # 給 Claude 頁面用
python3 build.py stub.js tests/test.html  # 產生測試用頁面（用替身取代 three.js）
```

`--artifact` 後面一定要先接 three.js 的網址，再接輸出檔名。

## 測試

測試用 Playwright 開瀏覽器：

- `timeline.js`：每條線的步驟時間不倒退、事件插在對的空檔、地點和人物都存在。
- `consistency.js`：劇本裡沒有高中版或已確認不符學制的用語；每段對話的說話者、站位都存在；前一天旗標全有或全無都能跑。
- `navigation.js`：三層樓每個地點、每個座位都走得到；國中生到班、國小生週三回班都能坐好；玩家能跨樓層走到三樓。
- `redesign-layout.js`：格局資料沒有在未經確認下改變。
- `continuous-clock.js`、`resume.js`、`extras.js`：時間推進、存檔讀檔、閒聊與加班小遊戲。
- `play2.js`、`play3.js`：自動玩完五條線的第一天、第二天，以及連玩三條線解鎖「一個月後」。

```bash
npm install
npx playwright install chromium
npm test
```

每次 push 和 PR，GitHub Actions 都會自動跑一次（`.github/workflows/test.yml`）。

測試用 `tests/stub.js` 取代 three.js，所以只能驗證遊戲邏輯。實際畫面由另一個 workflow（`.github/workflows/screenshots.yml`）用真的 three.js 在手機與桌面尺寸截圖。
